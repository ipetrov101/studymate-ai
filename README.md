# StudyMate AI — интеллектуальный помощник по учёбе

## Описание проекта

**StudyMate AI** — интеллектуальный помощник для организации учебного процесса студентов. Агент помогает планировать учебные задачи, контролировать сроки сдачи работ и отслеживать выполнение заданий.

Язык программирования проекта — **Python**.

## Планируемые возможности

- **Добавление заданий:** сохранение названия задания, учебной дисциплины и срока сдачи.
- **Контроль дедлайнов:** просмотр заданий с ближайшими сроками сдачи.
- **Отслеживание выполнения:** изменение статуса задания на выполненное.
- **Поиск просроченных работ:** определение заданий, срок сдачи которых истёк.
- **Планирование учёбы:** распределение задач по дням с учётом приоритетов и сроков.

## Примеры использования

### Запрос 1. Просмотр ближайших дедлайнов

**Запрос пользователя:**

> Покажи мои учебные задания, которые нужно сдать в ближайшие три дня, и отсортируй их по сроку сдачи.

**Ожидаемый результат:**

Агент выводит список заданий с названиями, учебными дисциплинами, сроками сдачи и статусами выполнения. Задания сортируются по возрастанию срока сдачи. Если подходящих заданий нет, агент сообщает об этом пользователю.

### Запрос 2. Планирование учебных задач

**Запрос пользователя:**

> Помоги распределить лабораторную по программированию, отчёт по физике и подготовку к зачёту по математике на ближайшие три дня.

**Ожидаемый результат:**

Агент составляет план на три дня, распределяет задачи по дням и предлагает приоритеты с учётом сроков сдачи и объёма работы. Если информации о сроках сдачи недостаточно, агент запрашивает уточнения.
