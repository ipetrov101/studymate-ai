
# StudyMate AI

StudyMate AI — консольный помощник для управления учебными задачами студентов.

Программа позволяет добавлять задания, указывать предмет и срок выполнения, просматривать список задач и отмечать выполненные задания. Данные сохраняются между запусками программы с помощью JSON-файла.

## Технологический стек

- Python 3.15.2
- JSON — хранение данных
- pytest — автоматизированное тестирование
- pytest-cov — измерение покрытия кода тестами
- Ruff 0.17.3 — проверка и форматирование кода
- Git и GitHub — контроль версий

## Структура проекта

- `main.py` — запуск программы и главный цикл.
- `commands.py` — обработка пользовательских команд.
- `tasks.py` — логика работы с задачами.
- `storage.py` — сохранение и загрузка задач из JSON-файла.
- `data/tasks.json` — файл с сохранёнными задачами, создаётся автоматически.
- `tests/` — автоматизированные тесты.
- `tests/conftest.py` — настройка тестового окружения.
- `requirements.txt` — список зависимостей.
- `.gitignore` — исключение служебных файлов из Git.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ipetrov101/studymate-ai.git
cd studymate-ai
```

### 2. Создание виртуального окружения

```bash
python3 -m venv .venv
```

### 3. Активация виртуального окружения

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 5. Запуск программы

```bash
python main.py
```

## Доступные команды

| Команда | Описание |
|---|---|
| `add` | Добавить учебную задачу |
| `list` | Показать список задач |
| `done` | Отметить задачу выполненной |
| `help` | Показать справку |
| `exit` | Завершить программу |

При добавлении задачи необходимо указать название, предмет и срок выполнения в формате ДД.ММ.ГГГГ.

При выполнении команды `done` программа запрашивает ID задачи.

## Хранение данных

Для хранения информации используется JSON-файл `data/tasks.json`.

Каждая задача содержит:
- уникальный идентификатор (ID);
- название;
- предмет;
- срок выполнения;
- статус выполнения.

При первом запуске, если файл с данными отсутствует, программа начинает работу с пустым списком задач.

При добавлении новой задачи и изменении её статуса данные автоматически сохраняются в JSON-файл.

При последующем запуске программа загружает сохранённые задачи, поэтому информация не теряется после завершения работы.

Предусмотрена обработка ошибок:
- отсутствие файла с данными;
- некорректный формат JSON;
- отсутствие обязательных полей;
- некорректные типы данных;
- ошибки чтения файла.

Если загрузить данные не удаётся, программа выводит сообщение об ошибке.

## Автоматизированное тестирование

Для проверки проекта используется библиотека pytest.

Запуск тестов:

```bash
python -m pytest -v
```

Тестируются:
- добавление новых задач;
- получение списка задач;
- изменение статуса выполнения;
- обработка уже выполненных задач;
- обработка несуществующих ID;
- сохранение и загрузка данных;
- работа при отсутствии файла;
- обработка некорректного JSON;
- обработка ошибок чтения и некорректных данных.

Для изоляции тестов используется временное хранилище, поэтому тестирование не изменяет реальные пользовательские данные.
