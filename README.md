# StudyMate AI

StudyMate AI — консольный помощник для управления учебными задачами студентов.

Программа позволяет добавлять задания, указывать предмет и срок выполнения, просматривать список задач и отмечать выполненные задания.

## Технологический стек

- Python 3.15.2
- Ruff 0.17.3 — проверка и форматирование кода
- Git и GitHub — контроль версий

## Структура проекта

- `main.py` — запуск программы и главный цикл.
- `commands.py` — обработка пользовательских команд.
- `tasks.py` — логика работы с задачами.
- `storage.py` — хранение задач в памяти.
- `requirements.txt` — список зависимостей.
- `.gitignore` — исключение служебных файлов из Git.

## Установка и запуск

### 1. Клонирование репозитория

git clone https://github.com/ipetrov101/studymate-ai.git

cd studymate-ai

### 2. Создание виртуального окружения

python3 -m venv .venv

### 3. Активация виртуального окружения

source .venv/bin/activate

### 4. Установка зависимостей

python -m pip install -r requirements.txt

### 5. Запуск программы

python main.py

## Доступные команды

| Команда | Описание |
|---|---|
| add | Добавить учебную задачу |
| list | Показать список задач |
| done | Отметить задачу выполненной |
| help | Показать справку |
| exit | Завершить программу |

При добавлении задачи необходимо указать название, предмет и срок выполнения в формате ДД.ММ.ГГГГ.

При выполнении команды done программа запрашивает ID задачи.

## Хранение данных

Задачи хранятся в оперативной памяти в виде списка словарей Python.

Каждая задача содержит уникальный ID, название, предмет, срок выполнения и статус.

После завершения программы данные не сохраняются.

## Проверка качества кода

Для проверки используется Ruff.

Проверка кода:

    ruff check .

Проверка форматирования:

    ruff format --check .

Автоматическое форматирование:

    ruff format .

## Примеры работы программы

### Пример 1. Добавление и просмотр задачи

    Введите команду: add
    Название задачи: Лабораторная работа №2
    Предмет: Программирование
    Срок выполнения (ДД.ММ.ГГГГ): 15.11.2026
    Задача добавлена. Её ID: 1

    Введите команду: list

    Ваши задачи:
    ID: 1 | Лабораторная работа №2 | Предмет: Программирование | Срок: 15.11.2026 | Статус: В процессе

### Пример 2. Выполнение задачи

    Введите команду: done
    Введите ID задачи: 1
    Задача отмечена как выполненная.

    Введите команду: list

    Ваши задачи:
    ID: 1 | Лабораторная работа №2 | Предмет: Программирование | Срок: 15.11.2026 | Статус: Выполнено

## Ограничения текущей версии

- Данные хранятся только во время работы программы.
- Интерфейс реализован в консоли.
- Подключение к интернету не требуется.
- Языковые модели не используются.
